描述

限 400 字以内，这段是 0 字。

无广告的中国象棋，为不太会用智能手机的长辈设计。 起因很具体：我爸想下棋，我给他装了五个 App，每个都有开屏广告。有的要登录、要充会员，有的把棋盘缩到屏幕一角塞广告位。他后来不下了，所以我自己写了一个。 三个设计支点：正文 19px、按钮 56px、零广告零注册零数据上传。术语全部翻成人话——不出现「深度/节点/评估分」，只说「这局你赢了」「这步要是走炮二平五就好了」。 会记战绩、连赢三局自动升档、连输自动降档，下完给一张说人话的教练卡：先夸一步做对的，再讲一步最该改的，最后给一条建议。前 3 档引擎零下载、可离线；后 3 档接 Pikafish。 开源，GPL-3.0。
