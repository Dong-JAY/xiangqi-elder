# 给爸爸的象棋软件 · 使用说明

## 一、先装到手机桌面（只做一次）

### 第 1 步：用浏览器打开链接

**不要在微信里直接点开！** 在微信里打开的话电脑水平会降到最低。

- 安卓手机：点右上角「⋮」→ 选「在浏览器中打开」
  - 微信里长按链接 → 选「在默认浏览器中打开」
- 或者：把这个链接复制到 Chrome / 夸克 / 手机自带浏览器，粘贴打开

### 第 2 步：添加到主屏幕

打开后，点浏览器右上角菜单：

- Chrome：⋮ → 「添加到主屏幕」/「安装应用」
- 夸克：≡ → 「添加到桌面」
- 手机自带浏览器：菜单 → 「添加到桌面」

**完成后**，手机桌面会出现一个「象棋」图标（木色棋子图案）。
以后点这个图标就能打开，和 App 一样，**断网也能玩**。

---

## 二、怎么玩

### 开始一局

打开后首屏有四个大按钮：

| 按钮 | 作用 |
|---|---|
| **和电脑下棋** | 正常对弈，下完有复盘讲解 |
| **挑战过去的自己** | 用你三个月前的水平跟你下，赢一次特别有成就感 |
| **我的成绩** | 看胜率、连胜、最近十局 |
| **和家里人下** | 同一台设备两个人轮流下 |

选「和电脑下棋」→ 选「我先走」或「电脑先走」→ 选难度 → 开始。

### 难度怎么选

| 档位 | 名字 | 说明 |
|---|---|---|
| 1~3 | 入门 / 初级 / 中级 | **不用下载任何东西，点开就能玩。建议先用「中级」** |
| 4~6 | 高级 / 大师 / 宗师 | 电脑更强。首次需要下载一个 50MB 的文件（用 WiFi 更快），下载完就能一直用 |

**不用自己选难度。** 连赢 3 局它会自动加难，连输 3 局会自动调简单，
而且会明确告诉你为什么变了（比如「你最近赢得多，我给你调难一点点了」）。

### 落子

**先点要动的棋子，再点要落的位置。** 绿色的点是能去的地方。

- 想反悔？点右下角「**悔棋**」
- 想重新开始？点「**重新开始**」
- 下完了想看讲解？点「**看复盘**」

---

## 三、复盘怎么看

下完一局（或点「看复盘」），会出现一张卡片：

```
这盘有进步的地方

👍 这步走得不错
   第 12 步你走马八进七，这一步很到位。

👉 这步可以更好
   你走：炮五进七
   这步之后你的炮就被吃了，当时应该走车九进八，那样就不会丢子。

💡 下一盘试试
   你第 12 步走的马八进七就挺好，下盘遇到类似局面可以再来一次。
```

**每盘只讲一步做对的、一步该改的** —— 不会给你一屏红字。

---

## 四、遇到问题怎么办

| 现象 | 怎么办 |
|---|---|
| 打开是空白页 | 检查是不是在微信里打开的，换成浏览器重新打开 |
| 高级/大师/宗师档打不开 | 那个 50MB 文件还没下载完，或当前环境不支持多线程（微信里就会这样） |
| 提示「设备不支持语音提示」 | 正常，这个功能是可选的，其他功能不受影响 |
| 战绩没了 | 浏览器清缓存会清掉战绩。在「我的成绩」页点「导出成绩」存一份备份 |
| 想重新装 | 删掉桌面图标，再按上面第一步重新添加 |

## 五、给儿子/女儿的说明

这个软件是专门为爸爸做的适老化版本：

- 界面是浅色高对比，字大、按钮大
- 所有技术术语都藏起来了（深度、节点数、评估分这些他看不到）
- 下完会有一张说人话的复盘卡，先夸后建议
- 难度自动调整，不用他操心
- 战绩存在他手机本地，不会上传到任何地方
- 没有广告，没有内购，不联网要钱

**源码是公开的**（GPL-3.0，因为核心引擎 Pikafish 是这个许可）。
在项目主页能看到全部代码，欢迎提改进建议。
